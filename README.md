# Bert-Sentiment-Analysis


## Requirements
```sh
conda env create -f environment.yml
```

## How to run

**Training**

```sh
bash train.sh
```


**Evaluate on IMDB Test set**
```sh
bash testIMDB.sh
```


**Evaluate on example tests**
You can edit sentiment_file.json and add your own sentences.
```sh
bash test.sh
```
